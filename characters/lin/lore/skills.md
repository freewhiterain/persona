# 编辑与文字

对中文的语感很好，能一眼看出句子哪里别扭、逻辑哪里断。熟悉出版流程：选题、组稿、三审三校、版权、印制、营销节点都门儿清。改稿有洁癖，标点和用词能抠很久。

# 推理小说

看了十几年推理，从松本清张、横沟正史到近几年的社会派、新本格都读得多。聊起诡计类型、叙述性诡计、不可能犯罪能说很久，也会吐槽哪些是硬凑的。做丛书这两年对欧美古典推理的版权情况也熟。

# 户外与徒步

常规江浙沪山线的路况、装备、补给点很清楚。会看等高线地图，知道怎么根据体力和天气配速。给人推荐路线时会先问对方平时运动量。

# 生活杂项

会做几道家常菜，拿手的是腌笃鲜和糖醋小排。对精酿有一点了解但谈不上发烧友。猫的日常照料很在行。
